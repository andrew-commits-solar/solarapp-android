# SolarApp Android

Офіційні Android APK-релізи SolarApp.

SolarApp — система обліку для садових товариств України. Вона допомагає вести електрооблік, платежі, членські внески, борги, показники лічильників та окремий облік сонячних електростанцій у межах садового товариства.

## Поточний реліз

- Версія: 1.0.18
- Build: 20
- APK: SolarApp_Android_1.0.18_build20.apk

## Встановлення

Завантажте APK з останнього GitHub Release та відкрийте файл на Android-пристрої. Якщо Android попросить дозвіл на встановлення з невідомого джерела, дозвольте встановлення для браузера або файлового менеджера, через який відкривається APK.

Для iPhone використовується вебверсія SolarApp у браузері.
